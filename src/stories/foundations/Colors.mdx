# Colors

All color comes from **semantic tokens** defined once in `src/app/globals.css` and exposed to Tailwind
through `@theme inline` (`--color-<name>: var(--<name>)`), so components write `bg-surface`, `text-muted`,
`border-border` — never raw hex.

Each token has a light value (`:root`) and a dark value (`:root[data-theme="dark"]`, and the OS preference when
`data-theme` is `system`). The root layout sets `data-theme` from the user's saved setting
(`src/app/layout.tsx`, `src/lib/current-theme.ts`). **Switch the Theme toolbar button above** — the values below
are read live from the page.

## Rules

- **Use tokens, not palette colors.** A few places still use Tailwind palette colors directly
  (`emerald-*` ≈ 30 uses, `amber-*` ≈ 25 uses, mostly status pills with a `dark:` override). Prefer `ok` / `warn`
  tokens for new code — they switch themes automatically.
- **Opacity modifiers are fine on tokens**: `bg-accent/90` (primary hover), `border-danger/20`, `bg-surface-subtle/30`.
- **Text on a solid accent** is `text-white` (light); one button uses `dark:text-black` because the dark accent
  (`#8d9bff`) is light. Check contrast with the Accessibility panel when adding solid fills.
