# Patterns (class recipes)

There is no `Button`, `Card`, `Input` or `Badge` component — those are **Tailwind class recipes repeated inline**.
This page records the canonical recipe for each, copied from the most common occurrences in the code, so new UI
stays consistent. (Extracting them into components is a good follow-up; these recipes are the spec.)
