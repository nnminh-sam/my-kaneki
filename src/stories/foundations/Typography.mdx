# Typography

**Families** — `Geist` (sans, `font-sans`) for everything and `Geist Mono` (`font-mono`) for code, IDs, paths, model
names and numbers in tables. Both are loaded by `next/font` in `src/app/layout.tsx` and wired to Tailwind through
`--font-sans` / `--font-mono` in `globals.css`.

**Density** — the UI is a dense workspace tool. The base reading size is small: `text-xs` (12px) is by far the
most used size (~320 uses), then `text-[11px]` (~130) for metadata and badges, `text-sm` (14px, ~90) for body text
in forms, inputs and messages. Larger sizes are reserved for page titles.

**Weights** — `font-medium` (500) and `font-semibold` (600) carry hierarchy (~180 uses each); `font-bold` is only
used for page titles.

## Long-form content

Markdown (notes, chat replies, LMS modules) is rendered by `MarkdownPreview` / `ChatMessage` with
`react-markdown` + `remark-gfm`, math via `remark-math` + `rehype-katex`, and Mermaid diagrams. See
**Primitives / MarkdownPreview**.
